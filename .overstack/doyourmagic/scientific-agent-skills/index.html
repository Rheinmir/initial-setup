01Cài Scientific Agent SkillsNgười dùng

Ba đường cài đã kiểm chứng bằng cách chạy thật: npx skills add (có --list và --skill để chọn subset), gh skill install (có provenance, ghim version), và clone tay dạng Agent Plugins. Kèm vị trí file thật quan sát được — --agent claude-code đặt vào .claude/skills/, --agent cursor vào .agents/skills/ dùng chung.

Sinh ra: thư mục skill trong host của bạn, kèm metadata truy vết trong frontmatter. Có ghi rõ ba chỗ README lệch với hành vi thật của CLI.
02Thẩm định trước khi càiNgười dùng · làm trước 01

Đọc SKILL.md mà không cài (gh skill preview), tra docs/security-report.json, và bảng đầy đủ 16 skill đang mang finding CRITICAL/HIGH — trích từ trường max_severity chứ không phải từ bảng tóm tắt. Kèm danh sách false positive hệ thống mà chính repo thừa nhận, để bạn dùng báo cáo đúng cách: chọn skill cần đọc kỹ, không phải kết tội.

Sinh ra: quyết định cài/không cài cho từng skill. Cảnh báo quan trọng: scanner fail open — thiếu API key nó trả exit 0, không phải lỗi.
03Dùng skill trong agent (chỉ prompt)Người dùng · hằng ngày

Mọi thứ trong file này gõ vào ô chat, không phải terminal. Cách gọi trúng skill khi hai skill phủ nhau, khung prompt 5 phần lấy từ docs/examples.md của repo, và bảng 25 skill cần credential kèm tên biến môi trường chính xác.

Sinh ra: artifact do skill định nghĩa. Bẫy lớn nhất: gate credential thất bại sẽ ẩn skill khỏi agent — nó biến mất chứ không báo lỗi.
04Chạy script bundled từ shellNgười dùng · hằng ngày

Mọi thứ trong file này gõ vào terminal. 90 skill ship CLI argparse chạy tất định, không tốn token — dùng được trong Makefile, cron, CI. Ba ví dụ đã chạy thật, một trong đó hoàn toàn offline thuần thư viện chuẩn.

Sinh ra: JSON/TSV và một exit code bạn bắt buộc phải branch — 3 = arXiv error feed đội lốt HTTP 200, 4 = phân trang thiếu hụt, và ở ba skill khác 1 nghĩa là "có finding" chứ không phải "crash".
05Ghim version, cập nhật, gỡ bỏNgười dùng · bảo trì

Ghim theo tag hoặc SHA, phân biệt metadata.version (của riêng skill) với github-tree-sha (của collection — cái mà công cụ update thật sự dùng), và một quy trình nâng cấp có bước diff. Diff một SKILL.md chính là diff hành vi agent.

Sinh ra: skill đã ghim và một đường nâng cấp có chủ đích. Lưu ý gh skill update --all bỏ qua skill đã ghim — nó không có nghĩa là mọi thứ đã mới nhất.
06Gate trong CI của dự án bạnNgười dùng · CI

Một workflow viết mới, tối thiểu — không phải bản sao pipeline nội bộ của repo skill. Gồm script phát hiện drift so upstream (đã chạy thật cả ca xanh lẫn ca đỏ) và bước validate spec chạy trên bản bạn đã commit.

Sinh ra: CI đỏ khi upstream sửa một skill bạn đã thẩm định, hoặc khi một skill không còn hợp lệ theo spec.

Cái gì thuộc phạm vi repo (và bốn loại bị từ chối như thường lệ), layout thư mục, đúng 6 field frontmatter hợp lệ, và ba cái bẫy YAML khiến skill "biến mất" — nổi bật là flow style JSON làm strictyaml từ chối cả document, kéo name và description chết chung.

Sinh ra: một skills/<name>/ hợp lệ, suite test ở đúng chỗ, và checklist trước PR. Có ghi lại một chỗ tài liệu lệch code: scripts/generate_skill_image.py mà AGENTS.md hướng dẫn không tồn tại trong repo.

Sinh ra: pass/fail cục bộ khớp với CI. Kèm trình tự chạy trước khi push, và cái nào chạy được mà không cần uv.
