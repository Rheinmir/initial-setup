Ba cái bẫy đã kiểm chứng — đọc trước khi gõ lệnh

  1. npx impeccable install --help không in help, nó cài thật. Không có TTY thì prompt tự nhận mặc định và cài global vào $HOME. Luôn thêm -y --scope=project.
  2. Target sai đường dẫn không làm CI đỏ: chỉ in Warning: cannot access … rồi thoát 0.
  3. npx gộp stderr vào stdout, nên 2> findings.txt bắt được file rỗng. Gọi ./node_modules/.bin/impeccable nếu cần tách luồng.

Nhánh tiêu thụ — dùng Impeccable trong dự án của bạn

  1. 01Cài vào dự án

    Đưa skill và hook design vào harness AI, đúng phạm vi bạn muốn. Bao gồm cả hai cái bẫy của install, ba đường cài (CLI, git submodule, plugin), hook manifest của từng harness, khối .gitignore cho .impeccable/, và một script Python liệt kê rồi gỡ sạch bản cài — kể cả khi lỡ cài nhầm global.

    Sinh ra: thư mục skill trong provider dir · file agent · hook manifest · 01-install-into-your-project.md

  2. 02Quét bằng CLI

    61 luật tất định, không LLM, không API key. File này giải thích ba engine (tĩnh, regex, Puppeteer) và cách CLI tự chọn, toàn bộ cờ, ý nghĩa mã thoát 0/1/2 đọc thẳng từ lời gọi process.exit, luật advisory không bao giờ làm rớt build, và cảnh báo DEGRADED khi chạy từ checkout chưa cài dependency.

    Sinh ra: finding ra stderr, JSON ra stdout, một mã thoát rẽ nhánh được · 02-detect-cli-scan.md

  3. 03Tinh chỉnh ignore

    Ba tầng waiver — comment inline theo file, config chung commit được, config local per-dev — và chọn tầng nào khi nào. Đủ bộ lệnh impeccable ignores, vòng lặp thật hạ 7 xuống 6 finding, và file config.json thật mà chính repo Impeccable commit làm mẫu tham chiếu.

    Sinh ra: mục detector trong .impeccable/config.json hoặc config.local.json · 03-tune-detector-ignores.md

  4. 04Cắm vào CI

    Một script cổng viết mới, tối giản, đã chạy thật trên cả ba nhánh 0/1/2 — không phải bản sao CI nội bộ của Impeccable. Kèm workflow GitHub Actions và GitLab, cách pin phiên bản, pre-commit hook, và hai cách hạ cổng dần trên codebase cũ để không đỏ hàng trăm finding ngày đầu.

    Sinh ra: bước CI có mã thoát rõ ràng + artifact impeccable.json · 04-ci-integration.md

  5. 0523 lệnh chat

    Toàn bộ lệnh /impeccable, đếm từ command-metadata.json chứ không từ README, nhóm theo việc: setup, review, sửa, đổi hướng thẩm mỹ, miền cụ thể. Cộng init và hai giá trị buildPath, cách ghim shortcut, điều kiện chạy live, và doctor để tự chẩn. Mọi thứ ở đây gõ trong chat, không phải terminal.

    Sinh ra: thay đổi code + artifact dưới .impeccable/ · 05-chat-commands.md

Nhánh đóng góp — sửa chính Impeccable

  1. 06Build và test

    Vòng lặp bun install → bun run build → test, kèm số đo thật. Hai chỗ hay trượt: cổng CI đòi commit cả generated provider output, và biến môi trường OPENCODE_CONFIG_DIR làm rớt 8 test vì bộ dò harness đọc máy thật của bạn. Cộng bảng đầy đủ các suite và bản đồ "muốn đổi X thì sửa file nào".

    Sinh ra: dist/ · provider dir đã regenerate (phải commit) · kết quả test · 06-contributor-build-and-test.md

  2. 07Build extension

    Chạy đúng 61 luật đó trên bất kỳ trang web nào đang mở. Thứ tự build bắt buộc (build:browser trước build:extension, nếu không detector nhúng vào sẽ là bản cũ), cách load unpacked trên Chrome và Firefox, các quyền MV3 xin và vì sao, cộng bảng so sánh khi nào dùng extension khi nào dùng CLI.

    Sinh ra: dist/extension.zip · dist/extension-firefox.zip · 07-browser-extension-build.md
